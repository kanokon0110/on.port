วิธีอัปโหลดขึ้น GitHub Pages

ขั้นตอนง่ายๆ ในการเผยแพร่เว็บไซต์ออนไลน์ฟรี

  1. บันทึกไฟล์นี้ไว้ในเครื่อง ตั้งชื่อว่า index.html
  2. ไปที่เว็บไซต์ GitHub.com ล็อกอิน แล้วคลิก New Repository
  3. ตั้งชื่อ Repository (เช่น my-portfolio) เลือกระดับเป็น Public แล้วคลิก Create
  4. คลิก uploading an existing file เพื่ออัปโหลดไฟล์ index.html ขึ้นไป
  5. ไปที่เมนู Settings → Pages → ตรง Build and deployment (Branch) ให้เลือกเป็น main หรือ master แล้วกด Save
  6. รอระบบทำงานประมาณ 1-2 นาที เว็บไซต์ของคุณจะออนไลน์ทันทีที่ลิงก์ https://yourusername.github.io/my-portfolio
